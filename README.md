## Dataset

This project uses the **Credit Card Fraud Detection** dataset from Kaggle.

- **Dataset Source:** [Credit Card Fraud Detection – Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
- **File Name:** `creditcard.csv`
- **Purpose:** To build a machine learning model that detects fraudulent credit card transactions.

### How to Download the Dataset

1. Visit the [Kaggle Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
2. Log in to your Kaggle account.
3. Download the dataset.
4. Extract `creditcard.csv` and place it in the project's root directory.

### Dataset Setup

After downloading, your project structure should look like this:

```text
real_time_fraud_detection_system/
├── creditcard.csv
├── notebooks/
├── src/
├── requirements.txt
├── README.md
└── .gitignore
```

**Note:** The dataset is not included in this GitHub repository because it exceeds GitHub's 100 MB file size limit. Download it from the Kaggle link above before running the project.
